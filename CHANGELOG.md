# Changelog

## v1.2.1 — 2026-10-26

- After Effects: **Zen Easy Rig** update.
  - Eyes: new "Separate controls per eye" option in Create Eyes and Make Simple Eyes, so each eye gets its own sliders (Top Lid L / R, Eye Open L / R…) to wink or move one pupil. Convergence stays shared.

## v1.2.0 — 2026-10-23

- After Effects: **Zen Easy Rig** update.
  - IK on 3 shape groups (or a shape layer that holds 3); the chain order is read from the drawings, and the hand group follows the controller's rotation.
  - Puppet pin chain IK: select the Puppet effect (or its layer) to rig all its pins.
  - Stroke IK: rounded elbows no longer loop or flip, and Flip Bend keeps the rounding.
  - Morph: one shared slider for the whole selection, a small "Each" button for one slider per property, the time-based slider goes on the layer when everything is on one layer, and sliders/controllers get descriptive names.

## v1.1.0 — 2026-10-19

- After Effects: new tool **Zen Easy Rig** (v1.0), a dockable rigging panel with IK, Face and Extras tabs.

## v1.0.0 — 2026-09-23

- Initial public release: 17 tools (14 After Effects + 3 Illustrator) + 1 deprecated script.
- After Effects: Create Face Rig, Delete If No Children Or Matte, Dissolve Parent, Freeze Property, Marker Batch Render, Marker Copy-Paste, Move And Trim, Null Group, Project Folder Helper, PuppetPin Null Creator, Simple Parent, Simple Parent (Unparented Only), Sync Shy Layers, Trim To Keys.
- Illustrator: Renombrator, Sort Layers Left to Right, Sort Layers Reading Order.
- Deprecated: 2D Parameter to Null (After Effects includes this natively).
- Released under MIT + Commons Clause.
